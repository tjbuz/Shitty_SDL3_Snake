# SDL3 Snake

My first SDL3 game written in C++.

## Controls

Arrow keys - Move

## Build

Requires SDL3 and MinGW.

Compile command:

g++ main.cpp -I "{path to include}\x86_64-w64-mingw32\include" -L "{path to lib}\SDL3-3.4.16\x86_64-w64-mingw32\lib" -lSDL3
